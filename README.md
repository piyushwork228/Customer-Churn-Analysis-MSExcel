# Telecom Customer Churn Analysis — Excel Dashboard

## Overview
An interactive Excel dashboard analyzing customer churn for a 
Telecom company with 7,043 customers and a 26.54% churn rate. 
Identifies key churn drivers across internet type, contract type, 
age groups, tenure, and geography — providing actionable insights 
to improve customer retention strategies.

## Key Metrics
| Metric | Value |
|--------|-------|
| Total Customers | 7,043 |
| Total Churn | 1,869 |
| Churn Rate | 26.54% |
| New Joiners | 454 |
| Customers Stayed | 4,720 |

## Visuals & Features
- KPI summary cards
- Churn by Category (Bar Chart)
- Churn Rate by Internet Type (Donut Chart)
- Churn Rate by Contract Type (Donut Chart)
- Top 15 Cities by Total Churn (Bar Chart)
- Churn by Age Group (Combo Chart)
- Churn by Tenure Group (Combo Chart)
- Interactive slicers by Gender and Marital Status

## Key Insights
- 26.54% churn rate — 1 in 4 customers leaving
- Competitor is the #1 reason for churn (841 customers)
- Fiber Optic users have the highest churn rate (40.72%)
- Month-to-Month contracts churn at 45.84% vs 2.55% for Two-Year
- Above 60 age group shows the steepest churn rate
- New customers (0–6 months) have the highest churn count
- San Diego is the highest churn city with 185 customers lost
